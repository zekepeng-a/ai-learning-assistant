# 给 Codex 的启动任务

请先阅读本文件与 [参考研究](REFERENCE_RESEARCH.md)，然后在本仓库推进学习助手产品。你负责实现；当前研究不构成已冻结架构。

## 已确定的方向

- 本仓库为 `zekepeng-a/ai-learning-assistant`，替代已废弃并删除的旧实验。
- 目标入口仍是：用户给出专业或技能及具体目标，得到领域理解与学习路径，并能开始学习。
- 旧项目用于测试 pCOS；新项目按真实学习者的实际任务判断价值。pCOS 不作为开发或运行依赖。
- 本轮只创建了研究与交接文档。尚未实现功能、验证需求或证明学习效果。
- 开发者主要在 Windows + PowerShell 使用 Codex；优先中文界面、云端模型 API，无需本地独显。

## 先做复用验证，再实现首个完整流程

优先检查：
1. Bloom：https://github.com/Li-Evan/Bloom
2. DeepTutor：https://github.com/HKUDS/DeepTutor
3. OATutor：https://github.com/CAHLR/OATutor

研究中读到的关键实现和固定版本见参考文档。拉取时核对新变化；不同版本不得混写。参考项目放在独立目录；若决定引入代码，保留许可证、原作者署名与来源，并记录上游 commit。

先运行 Bloom 的 Web 路径，检查创建课程、阅读、批注、反馈如何改变下一课；同时对 DeepTutor 做同任务的针对性比较。先只安装所需能力，不把所有可选集成配置齐。不要将读 README 写成运行成功。

在现有能力能直接满足目标时，优先复用/扩展。用实际修改范围、启动成本、可维护性和核心流程完整度选择实现方式；无需为了使用新技术更换栈。若 Bloom 可低成本承担主体，优先在它上面改造；若需要大面积重写，解释具体阻碍，再选更小实现。

请简短报告实际选择与理由，然后继续可逆实现，不必为每个局部技术选择等待批准。重大产品方向变化、明显扩大范围或新费用需要单独说明。

## 首版建议范围（PROPOSAL，可由试用证据修订）

保留专业/技能入口，先围绕用户选择的一个可检验学习目标完成一次学习过程。首个试用目标由用户指定；若尚缺答案，可问一个“你希望先学会什么具体事情”的问题，同时继续独立的环境准备、源码检查与通用流程工作。不要替用户把整个产品锁死为编程、考研或背词。

建议首个流程：

1. 输入主题、想完成的事情和已有基础；通过一个小问题或任务观察起点，允许用户跳过或修正。
2. 呈现简短领域结构：对象/概念、关系、规则、典型问题与适用边界。提供可查看来源的资料；资料不足时明确当前依据，不能编造书名、课程或链接。
3. 给出与目标有关的少量步骤，直接进入第一段讲解和一个具体练习，避免只交付长路线。
4. 接收用户实际回答/产物，给出有依据的反馈；保留原始回答、是否借助提示与评估依据。开放式回答不能简单用字面相等/关键词命中宣判理解。
5. 下一步真正使用刚才的错误、回答和困惑，解释为什么补基础、换例子或继续；允许用户调整。关闭并重开后可以接续。

不需要首版同时拥有海量题库、完整图谱、通用记忆框架、FSRS/BKT、多个教学 Agent、动态布局或商业后台；只有被具体任务证明需要的部分才加入。

## 必须纠正的参考实现问题

Bloom 的 `_auto_check_mastery` 会用课文中的标记勾选“掌握项”。复用时将内容覆盖与学习者表现区分；读过、生成过和点击完成都不能自动证明掌握。

记录应进入实际教学输入和下一步选择，而不只出现在统计页。模型给出的诊断是可修正判断；不确定时承认不确定，不能捏造分数或自信地误判。

## 验收用真实过程

先选一个边界清楚的主题做完整试用，再用另一个领域检查明显写死的假设；这不构成“适用于所有学科”的证明。

重点检查：
- 用户可以从目标走到实际练习，无需自行读代码才能使用。
- 相同目标下，一次明显错误与一次合理回答会触发有区别且说得通的反馈/下一步；保留输入和结果，不能只检查提示词里写了“自适应”。
- 可以查看教学依据；来源存在与来源支持结论分开检查。
- 重启能继续，失败保留已有内容，有清楚的重试入口。
- 用相同资料、模型和可比预算做直接聊天基线，观察新工具究竟减少了哪些操作、改善了什么学习行为；不能保证一定胜出。
- 软件测试覆盖核心数据与流程风险。mock 测试、真实 API 试用、真实学习表现分开报告。没有凭据时可先验证软件链路，但不得宣称模型输出已验收。

真实模型调用使用用户指定的现有配置与预算。不要把 API Key 写进源码、Git、日志或聊天。模型 ID 和 endpoint 可配置；不要沿用旧实验的固定模型名。先做本地版本，联网部署和多用户能力后续按实际需要决定。
