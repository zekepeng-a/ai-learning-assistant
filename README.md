# AI Learning Assistant

面向具体专业或技能的学习助手：帮助学习者理解领域结构、选择学习路径，并在练习与反馈中推进。

当前状态：研究与开发交接已建立，尚无产品实现。需求、学习效果和持续使用价值待验证。

## 开始开发

让 Codex 读取上述两份文档，先试运行并比较可复用项目，再推进首个完整学习流程。优先复用或扩展现成实现，具体技术栈由运行证据决定。

产品与已废弃的 pCOS 测试实验分开推进。当前未选定生产架构，也未宣称适用于所有学科或已证明学习收益。
